# 📦 Archive of Development & Calculation Scripts (ไฟล์สคริปต์ที่พัฒนาเสร็จแล้ว)

โฟลเดอร์นี้รวบรวมไฟล์สคริปต์ Python และไฟล์ข้อมูลชั่วคราวที่ใช้ในการคำนวณพิกัดดาราศาสตร์และสร้างฐานข้อมูลกลุ่มดาว ซึ่ง**ไม่ได้ถูกเรียกใช้โดยตรงในการแสดงผลหน้าเว็บ** (หน้าเว็บใช้งานเฉพาะไฟล์ในรูทโฟลเดอร์, `css/`, และ `js/`)

### รายชื่อไฟล์ในโฟลเดอร์นี้:
1. `build_full_constellations.py` - สคริปต์คำนวณและสร้างฐานข้อมูล 12 กลุ่มดาวเริ่มต้น
2. `compute_astronomy.py` - สคริปต์แปลงพิกัดทรงกลมฟ้า J2000 (RA / Dec)
3. `deep_verify.py` - สคริปต์ตรวจสอบความถูกต้องของเส้นและ SVG
4. `generate_constellations_dataset.py` - สคริปต์สร้างโครงสร้างข้อมูลกลุ่มดาว
5. `generate_updated_constellations.py` - สคริปต์ปรับแต่ง 5 กลุ่มดาวตามภาพจริง
6. `projected_stars.json` - ข้อมูลพิกัดดาวที่คำนวณไว้ชั่วคราว
7. `test_builder.py` - สคริปต์ทดสอบการสร้างข้อมูล
8. `update_5_constellations.py` - สคริปต์ทดสอบมาตราส่วนพิกัด
9. `verify_constellations.py` - สคริปต์ทดสอบโครงสร้างข้อมูล
